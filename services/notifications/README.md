# Notifications (רז)
מחקר ובחירת כלי לשליחת הודעות (WhatsApp / SMS / Push) לשחקנים ולהורים, ובניית שליחה אוטומטית של עדכונים ותזכורות.
עובדים רק בתיקייה הזו, ב-branch `feature/notifications`.

נמענים לעדכון לוח: מאמני הקבוצה שנגעה, וגם כל איש הנהלה (`staff.receives_all_updates`) — מנהל מקצועי, מנהל מחלקה, מנהל חטיבה צעירה, ראש מערך שוערים — לכל הקבוצות. פרטי הקשר הם הטלפון והאימייל שבאותה שורת צוות. הרשימה נבנית ב-`lib/update-recipients.ts` (`recipientsForTeams`).
