# Shared data contract

כאן מוגדר מבנה הנתונים המשותף שכל החלקים משתמשים בו, מחולק לחמישה תחומים (כמו `db/schema/`).

שינוי כאן דורש PR ואישור של Omer (ראו `.github/CODEOWNERS`).

## קבצים לפי תחום

| תחום | קובץ | תוכן |
|------|------|------|
| נתוני קבוצות | `team.ts` | קודי רמות גיל (`team_age_bands`) |
| נתוני מגרשים | `pitch.ts` | קודי מגרשים וחלוקות, `PitchRef` |
| נתוני אימונים | `practice.ts` | משכי אימון, סבבים, בית ספר, `slot_training_details` |
| נתוני משחקים | `game.ts` | סוגי slot, משחק, ערים, אירועים חיצוניים |
| נתוני כוח אדם | `personnel.ts` | צוות, היעדרות, חובשים, נהגים |

- `constants.ts` / `types.ts` — ייצוא מרוכז לאחור (imports ישנים).
- `index.ts` — ייצוא כל התחומים.

ה-UI עדיין משתמש ב-`lib/slot-types.ts` לצבעים; בעתיד ניתן ליישר צבעים מ-`pitches.color_key`.
