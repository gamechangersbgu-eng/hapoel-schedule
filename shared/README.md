# Shared data contract
כאן מוגדר מבנה הנתונים המשותף (משחק, אימון, מגרש, קבוצה) שכל החלקים משתמשים בו.
שינוי כאן דורש PR ואישור של Omer (ראו `.github/CODEOWNERS`).

## קבצים
- `constants.ts` — מזהי lookup (מגרשים, חלוקות, סוגי היעדרות) שמתאימים לטבלאות ב-`db/schema.ts`.
- `types.ts` — טיפוסי DTO/Ref לשימוש בין מודולים (מגרש, סבב, משחק, אימון, צוות) בלי לייבא Drizzle.
- `index.ts` — ייצוא מרוכז.

ה-UI עדיין משתמש ב-`lib/slot-types.ts` לצבעים; בעתיד ניתן ליישר צבעים מ-`pitches.color_key`.
